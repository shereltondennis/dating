# HeartBridge MVP

## Run locally

```powershell
node server.js
```

Open `http://localhost:3000`.

## Features included

- Account registration + login
- Token-based authentication
- Profile creation and editing
- Member search and filtering
- Private one-to-one messaging
- File-based persistence in `data/store.json`

## Notes

- This is an MVP demo and not production hardened.
- For production, add HTTPS, secure cookies/JWT rotation, rate limiting, and a real database.
